# Security Headers Workshop

A small workshop for learning web security headers, focused on:
- Same-Origin Policy (SOP) and CORS
- Content Security Policy (CSP)

## Structure

- `presentation/` — slides and talking points for the workshop session
- `demo/` — hands-on demo/practice project(s) for attendees to explore SOP/CORS and CSP issues and fixes

## Status

Basic folder structure only. Presentation format and demo tech stack are not yet decided.
